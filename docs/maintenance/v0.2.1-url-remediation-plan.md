## 6. Evidence policy

1. Canonical YAML remains source of truth.
2. HTTP/network observations are triage inputs only, never sole lifecycle proof.
3. Redirects never justify bulk replacement.
4. Archived repositories require product-boundary validation.
5. Primary sources only: official site/docs, canonical org repos, release feeds, authoritative license files, migration/deprecation notices.
6. Inconclusive evidence remains unresolved (`needs-review`) until authoritative proof is gathered.
